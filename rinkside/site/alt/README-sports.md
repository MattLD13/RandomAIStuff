# Alternate logos for Courtside, Sideline, Dugout and Pitchside

By default each team's background uses its secondary logo from ESPN. To use a different one,
drop an image in a folder named for the league, using the team's ESPN abbreviation:

    alt/nba/NY.png    alt/nfl/NYG.svg    alt/mlb/NYY.png    alt/mls/NYC.webp

It takes effect on the next build. PNG or SVG with a transparent background works best.
